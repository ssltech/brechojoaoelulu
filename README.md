# Brechó João e Lulu

Catálogo responsivo de produtos, com área de gestão para cadastro e marcação de itens vendidos.

O site usa Vinext/React, banco D1 e armazenamento R2 na hospedagem Sites. A senha de gestão fica em `ADMIN_PASSWORD` nas variáveis de ambiente da hospedagem; nunca deve ser colocada neste repositório.
